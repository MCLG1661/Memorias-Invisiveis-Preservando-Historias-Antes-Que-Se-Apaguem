##🌟 Sobre o Projeto

**Memórias Invisíveis** é um projeto de produto digital criado para explorar 
como a tecnologia pode contribuir para a preservação de histórias, experiências 
e memórias familiares entre diferentes gerações.

A proposta parte de uma ideia simples :

> Muitas das histórias mais importantes de uma família nunca foram registradas.

Experiências de infância, histórias de trabalho, receitas, tradições, viagens, 
conselhos e acontecimentos familiares podem existir apenas na memória e na 
transmissão oral.

O projeto propõe uma experiência digital para incentivar o registro e a 
organização desse patrimônio afetivo. 

----

##✨ Funcionalidades Principais

🎙️ Captura de Histórias

- Guias passo a passo para entrevistas intergeracionais
- Sugestões de perguntas que desbloqueiam memórias significativas
- Formatos diversos: áudio, vídeo, texto e fotos digitalizadas

##🗂️ Organização e Preservação

- Sistema de catalogação por temas: amor, trabalho, infância, tradições
- Linha do tempo familiar interativa
- Backup seguro em nuvem com acesso controlado

##🤝 Comunidade

- Espaço para compartilhamento de histórias (com permissão)
- Fórum para troca de experiências e dicas
- Eventos online de contação de histórias

##📚 Recursos Educativos

- Materiais sobre como conversar com idosos com perda de memória
- Tutoriais sobre preservação de fotos e documentos antigos
- Informações sobre demência e comunicação compassiva
